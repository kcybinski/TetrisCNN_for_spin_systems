# requirements.txt -- pip-only install path for TetrisCNN.
#
# The SUPPORTED install path is conda: `conda env create -f environment.yml` (see that file for
# the full "why this pin exists" commentary this file mirrors). Use this file only if you are not
# using conda -- e.g. `python -m venv .venv && pip install -r requirements.txt`.
#
# Symbolic regression (PySR, with the Julia runtime it brings, and plotly for its interactive
# plots) is NOT included: it is an optional, separately run route (sr_toolbox.py). Add it with
# `pip install -r requirements-sr.txt`, which also documents the Julia side.
#
# Tk note: environment.yml also pins conda-forge's `tk` package, which supplies the OS-level
# Tcl/Tk libraries backing Python's stdlib `tkinter` (used by tetriscnn/utils.py:pick_directory()'s
# non-notebook directory-picker dialog). There is no pip-installable equivalent -- pip assumes the
# system Python already has Tk support (true for python.org installers and most Linux distro
# packages, sometimes false for a from-source build). If `import tkinter` fails, install Tk via
# your OS package manager (e.g. `brew install tcl-tk` on macOS, `apt install python3-tk` on
# Debian/Ubuntu) rather than via this file.
